# Status and Limitations

AITIR is currently an early-stage framework and public documentation project.

## Current Status

- Framework concept: defined
- Architecture: documented
- Public-sector use cases: documented
- Future roadmap: documented
- Technical exhibit: available separately for petition and professional review
- External review: being sought through academic, practitioner, and government-technology recommendation letters

## What AITIR Is

AITIR is:

- a framework for identity-centered threat detection and response prioritization;
- a public-sector cybersecurity model;
- a documentation and research project;
- a foundation for future publications, technical refinement, and practitioner feedback.

## What AITIR Is Not Yet

AITIR is not yet:

- a certified product;
- a deployed commercial platform;
- a substitute for agency security policy;
- a replacement for NIST, CISA, or agency guidance;
- a claim of broad external adoption;
- a disclosure of any employer's confidential infrastructure.

## Responsible Use

This public version intentionally excludes:

- confidential employer information;
- internal law-enforcement system details;
- sensitive infrastructure diagrams;
- nonpublic security procedures;
- credentials, access methods, or operational security data.

## Why This Matters for Review

The purpose of public documentation is to make the framework understandable, reviewable, and portable. It allows outside experts, practitioners, and adjudicators to see that AITIR is more than a private idea, while keeping the claims accurate and appropriately limited.
