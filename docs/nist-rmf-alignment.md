# NIST RMF and Control Alignment

AITIR is not a substitute for NIST guidance, agency policy, or formal compliance assessment. It is a framework that can support public-sector cybersecurity teams by connecting identity-centered threat events to risk-based review and response workflows.

## NIST Risk Management Framework Fit

AITIR can support RMF-style thinking by helping teams:

- identify identity and access risks;
- categorize systems based on sensitivity and operational importance;
- select relevant access, audit, monitoring, and response controls;
- monitor events and control effectiveness;
- document review and response decisions.

## Relevant Control Families

AITIR may align with control areas commonly associated with:

- access control;
- identification and authentication;
- audit and accountability;
- incident response;
- risk assessment;
- system and communications protection;
- configuration management;
- contingency planning.

## Practical Alignment

AITIR is designed to translate control evidence into operational questions:

- Which identity event needs review first?
- Which system owner should be involved?
- What evidence supports escalation?
- What response step is proportionate?
- How should the decision be documented?

This makes the framework useful for agencies that need both security operations and defensible documentation.
